# SMUK precision wordmark

Original monochrome artwork for SMUK PCB silkscreen and schematic sheets. The ±
mark refers to bipolar source/measure operation; angular, solid lettering remains
readable when reduced. All production artwork uses polygons, with no font
installation, embedded text, gradients, raster tracing, copper, or electrical pins.

![Black and white wordmark and PCB preview](smuk-logo-preview.png)

## Files

| File | Use |
|---|---|
| `smuk-logo.svg` | Black SVG master with transparent background |
| `smuk-logo-white.svg` | White SVG for dark backgrounds |
| `smuk-logo-preview.png` | Presentation preview; not manufacturing artwork |
| `SMUK_Logos.pretty/SMUK_Logo_24.4mm.kicad_mod` | Larger F.SilkS footprint |
| `SMUK_Logos.pretty/SMUK_Logo_16mm.kicad_mod` | Compact F.SilkS footprint |
| `SMUK_Logos.kicad_sym` | Schematic library containing `SMUK_Logo` |
| `generate.py` | Standard-library Python generator for both SVGs and KiCad libraries |

Sizes in footprint names refer to the full design canvas. The 24.4 mm version
has approximately 22.5 × 4.2 mm visible artwork; the 16 mm version has approximately
14.75 × 2.75 mm visible artwork. Canvas dimensions include whitespace. Keep
additional clearance around the visible logo; do not place pads or silkscreen
text in its negative spaces.

## PCB use

Register `SMUK_Logos.pretty` as a project footprint library, then place either
logo footprint. Both contain only front-silkscreen artwork and hidden descriptive
fields. They are board-only and excluded from BOM and position outputs. For a
back-side logo, flip the footprint in the PCB editor; do not manually mirror the
SVG and then flip again.

Check the actual manufacturer's silkscreen minimum feature/spacing rules and
silkscreen-to-mask clearances at the chosen size. Avoid further shrinking without
reviewing the diagonal features and small gaps. Inspect the plotted silkscreen
and run PCB DRC before finalizing a layout revision.

## Schematic use

Register `SMUK_Logos.kicad_sym` as a project symbol library and place
`SMUK_Logo`. This is a graphical symbol with no pins, excluded from simulation,
BOM and PCB transfer; its reference and value are hidden. Place it in a clear
area of the sheet. This does not modify the drawing-sheet/title-block template.

Run schematic ERC after placement. No existing project library tables, schematic
sheets, PCB layouts, or production exports were modified when creating these assets.

## Regeneration and validation

```sh
python3 hardware/branding/generate.py
```

The geometry is defined once in `generate.py`; SVGs, footprints and schematic
symbol are derived from those same polygons. The PNG is a separate presentation
render and is not regenerated by this script.

Validated using the installed KiCad 10 CLI: the schematic symbol and both
footprints load and export to SVG successfully. This checks library syntax and
rendering, not placement-specific ERC/DRC or manufacturer approval.
